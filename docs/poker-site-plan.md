# ポーカー店の検索・口コミサイト：競合、収益化、名前（2026-11-25）

## 結論
- 競合サイトは **6 つ以上** ある。店の一覧と大きな大会の日程は、すでに埋まっている。
- 空いているのは、次の 3 点。ここを差にする。
  1. **口コミ**（実際に行った人の声）
  2. **条件での絞り込み**（初心者講習、一人で行きやすい、禁煙、平日夜の大会、参加費の幅）
  3. **店ごとの日々の大会**を、日付と地域で探せること（「今夜、渋谷で出られる大会」）
- 収益の柱は「**店の有料プラン（自分で申し込む形、営業なし）**」。ここに、アプリのサブスクと遠征の宿泊アフィリエイトを足す。
- オンラインカジノのアフィリエイトは **やらない**（競合の一部はやっている。違法な賭博への誘導の禁止は 2025 年 9 月施行）。

## 収益化の道筋
| 時期 | 収益源 | 中身 | 目安 |
|---|---|---|---|
| 0〜6 か月 | 無し（集める期間） | 東京 23 区を網羅。口コミと大会を集める | 費用は、ドメイン代（年 数千円）とサーバー代（無料枠）のみ |
| 6〜12 か月 | **店の有料プラン** | 掲載は無料のまま。店が自分の掲載を「公式」として引き継ぎ、有料で、写真を増やせる、大会をまとめて登録して SNS にも流せる、閲覧数が分かる、初来店クーポンを載せられる。**表示の順番は売らない** | 月 3,000〜5,000 円。全国 600 店の 15% で、月 27〜45 万円 |
| 12 か月〜 | アプリのサブスク | 成績の記録、行きたい店や大会の通知、遠征の計画 | 月 480 円 × 500 人で月 24 万円 |
| 随時 | 遠征の宿泊アフィリエイト | 大会会場の近くのホテル（楽天トラベル、じゃらん） | 小さい（月 数万円） |
| 随時 | 広告 | ポーカー用品、本 | 小さい |

営業をしない仕組み：店は検索で自分の店のページを見つけ、「店主の方はこちら（無料）」から登録する。口コミが付くほど、店にとって登録する理由が増える。

やらないこと：オンラインカジノや換金を伴うもののアフィリエイト、表示の順番の販売、口コミの削除の販売。

## 名前とドメイン
SEO の観点：
- ドメイン名にキーワードが入っていても、順位への効果は小さい。効くのは、ページの中身、地域ごとのページ（例：「渋谷のポーカー店」）、口コミの量。
- ただし、検索結果で何のサイトか一目で分かる名前は、クリックされやすい。「ポーカー」と「店」または「地図」が入っているとよい。
- `.jp` は日本向けの信頼感がある（個人でも取れる）。

候補（2026-11-25 時点の DNS では未登録の見込み。取得前に再確認する）：
| サイト名 | ドメイン | 良い点 |
|---|---|---|
| **ポーカーマップ** | pokermap.jp | 短く、何のサイトか分かる。「地図で探す」の機能と一致 |
| ポーカー店ガイド | pokerguide.jp | 「ポーカー 店」での検索と一致。将来、大会や遠征にも広げやすい |
| ポーカーどこ | pokerdoko.jp | 覚えやすい。「近くでどこでやってるか」の用件と一致 |
| ホールデムマップ | holdemmap.jp | 独自性があるが、「ポーカー」で検索する人には少し遠い |

おすすめは **ポーカーマップ（pokermap.jp）**。取得はゲート 0 の扱いと同じく、作り始めると決めてから。

## 追記（同日）：海外の大会を日本語でまとめる案
- 日本語で、海外の大会への参加方法をまとめた総合的なガイドは、検索では見つからなかった。The Royal Social Club は海外の大会も扱うが、オンラインカジノのアフィリエイトがある。
- 国内の大型大会は法的にグレーとされ、2026 年の WPT 東京は開催が見送られた。海外の大会は、国内の規制が変わったときの保険にもなる。
- 収益：海外の遠征は 1 回あたりの支出が大きい（ラスベガスで航空券と宿泊に 20〜40 万円）。宿泊、航空券、海外旅行保険、eSIM や Wi-Fi のアフィリエイトは、広告より 1 人あたりの単価が高い。
- 守ること：海外の大会の予選の多くはオンラインポーカー（日本からの参加は違法）で行われる。**オンライン予選へのリンクや案内は載せない**。現地で参加する方法だけを載せる。
- 足を使わずに机の上で作れるので、育休中に進めやすい。
- 次：キーワードプランナーで需要を確かめる（WSOP、APT など）。

## 追記（同日）：海外の需要の数字（キーワードプランナー、2025-11〜2026-10、月平均）
| 語句 | 検索数 |
|---|---|
| wsop | 5,000 |
| apt / ept / wpt ポーカー | 各 500 |
| ラスベガス / マカオ / マニラ / 台湾 / 韓国 ポーカー | 各 500 |
| ポーカー 海外 | 500 |
| triton ポーカー、wsop 参加方法、海外 ポーカー 大会 | 各 50 |
| ポーカー 遠征 | ほぼ 0 |

- 合計は約 1 万回。国内（JOPT は月 1〜10 万回）の数分の 1。
- 「wsop」の多くは、結果や配信を見たい人と考えられる。**実際に行く計画を立てる人**に近いのは、地名＋ポーカー（計 2,500 回）と「参加方法」。
- アジアの 4 地域（マカオ、マニラ、台湾、韓国）の合計は、ラスベガスの 4 倍。近くて安く行けるので、行く人の数はこちらが多いと見る。
- PokerDiary は、開発者本人の端末からも 403 で開けない。閉鎖か停止の可能性が高い。

判断：海外だけでは集客が小さい。**国内と海外を 1 つのサイトにまとめ、海外は「独自性と収益（旅行の紹介料）」、国内は「集客」を担う**。作る順は、競合がいない海外（アジア中心）を先にし、次に東京の店。
