# 東京の店の一覧づくり

## 方針
- 他のサイトや紹介記事は、**店名と地域を知る手がかり**としてだけ使う。文章、写真、料金表は写さない。
- 住所、営業時間、定休日、禁煙かどうかは「事実」なので、出典（店が自分で載せている掲載ページ、公式サイト、記事）と確認日を付けて載せる。
- いずれ、店の公式サイトか公式 SNS で確認し直す。店主が自分で更新できる仕組みを用意する。

## 分かったこと
- 店の情報は、ホットペッパー、食べログ、X、Instagram、Google マップに**ばらばらに**ある。1 か所で、条件（専門店か、禁煙か、深夜か）で探せる場所はない。これが、このサイトの存在理由になる。
- 店の入れ替わりが速い（開店、閉店、移転）。**確認日を表示し、定期的に確認し直す仕組み**が要る。

## 追記（2026-11-26）：Google の公式 API で網羅
- Google Places API（Text Search、75 回の検索、無料枠の範囲）で 23 区を「ポーカー」「アミューズメントカジノ」で検索。360 か所から、ポーカーに関係する店を選び分けた。
- 23 区の掲載は **180 店**（48 店から増加）。区別の上位：港区 33、新宿区 32、渋谷区 17、豊島区 15、千代田区 11。
- Google の規約に合わせ、保存するのは place_id、店名、区、公式サイトの URL、営業状況と確認日だけ。住所や営業時間は、店の掲載情報や公式サイトを出典にして順に足す。住所が未掲載の店は、Google マップへのリンクで場所を示す。
- 32 店は、ポーカーを遊べるかがまだ分からないため「ポーカーの有無を確認中」と表示。
- 閉店（Google で CLOSED_PERMANENTLY）の 1 店は除外。
- GoodGame Poker Live は、オンラインポーカーの GGPoker との提携を公表しているため、店は載せるが公式サイトにはリンクしない。
- API キーはリポジトリに保存していない。
