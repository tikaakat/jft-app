# 公開の判断材料（2026-11-26）

## 結論
- 中身は公開できる水準に届いた：海外ガイド（共通＋5 地域、18 大会）、東京 23 区の 48 店（区ごとの 17 ページ）、編集方針。全 26 ページ。
- 公開にかかる費用は **ドメイン代の年 1,500〜4,000 円程度だけ**。サーバーは無料。
- あなたの作業は 3 つ（計 30 分ほど）：ドメインの取得、公開先の無料登録、検索の管理ツールの登録。

## 決めること
### 1. ドメイン
| 候補 | 状態（DNS での確認） | 費用の目安（年） | 備考 |
|---|---|---|---|
| **pokermap.jp** | 未登録の見込み | 3,000〜4,000 円 | 日本向けの信頼感。おすすめ |
| poker-map.net | 未登録の見込み | 1,500〜2,000 円 | 安い |
| pokermap.com | **登録済み** | — | 使えない |
- 検索順位への影響は、.jp と .net でほぼ変わらない。日本のサイトらしさで .jp を勧める。
- 取得する場所：.jp は国内の登録業者（お名前.com、ムームードメインなど）。初年度の割引より、**2 年目以降の更新料**で比べる。
- 個人で取る場合、登録者の情報を公開しない設定（WHOIS の代理公開）を必ず使う。

### 2. 公開先（無料）
| 候補 | 良い点 | 注意 |
|---|---|---|
| **Cloudflare Pages**（おすすめ） | 無料、速い、アクセス解析が無料で付く（Cookie なし） | アカウントの登録が要る |
| GitHub Pages | 今の GitHub アカウントで使える | 非公開のリポジトリからは有料プランが要る。サイトだけの公開リポジトリを分ける必要がある |

### 3. 検索の管理ツール
- Google Search Console（今の Google アカウントで登録）：どの言葉で何回表示・クリックされたかが分かる。ゲート A と B の数字はここで測る。

### 4. 訂正と店主からの登録の窓口
- 最初は Google フォーム（無料、今の Google アカウントで作れる）。項目は Claude が用意する。

## 公開前に Claude がやること
1. サイトのドメインを設定し直す（build.py の BASE_URL）。
2. 「店主の方へ」のページに、フォームのリンクを入れる。
3. アクセス解析と Search Console の確認用のタグを入れる。
4. 公開後の最初の 1 か月は、毎週、大会情報と店の確認日を更新する。

## 公開の前に気をつけること
- 店の情報は、店が自分で載せている情報を出典にしているが、**店から削除の依頼があれば、すぐに応じる**。
- 「中止の情報あり」「公式で要確認」の表示を消さない（間違いのまま載せない）。
- オンラインカジノ・オンラインポーカーのリンクが入っていないかを、公開のたびに機械で確認する（Claude がチェックを用意する）。
