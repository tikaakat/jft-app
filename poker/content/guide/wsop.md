# WSOP に出るまでの手順

> 公式情報で確認できた事実と手順だけを載せています。登録の方法や支払いの方法は年ごとに変わることがあるため、必ず主催者の最新の案内で確認してください。

## 1. 日程が出たら（例年 2 月ごろ）
- [ ] 日程の発表を待つ。2026 年は 2 月中旬に発表され、5 月 26 日〜7 月 13 日に Horseshoe Las Vegas と Paris Las Vegas で開かれた（[アメリカのガイド](/guide/lasvegas/)）。
- [ ] 出たいイベントの参加費、開始時刻、Day の構成、遅れての登録の締切を確認する。
- [ ] 勝ち残った場合の日数を足して、滞在日数を決める。

## 2. 出発の 2〜3 か月前
- [ ] **ESTA** を申請する（40.62 ドル。公式サイトから申請し、代行サイトの上乗せ料金に注意）。
- [ ] パスポートの残りの有効期間を確認する。
- [ ] **ITIN（米国の納税者番号）** の準備を検討する。賞金の 30% の源泉徴収を避ける手続き（W-8BEN）に必要になる。取得には時間がかかるとされるため、早めに専門家や公式の案内で確認する（[米国の会計事務所の解説](https://kondlercpa.com/2023/06/07/wsop-2023-itin-issues-persist-for-nonresidents/)）。
- [ ] 航空券とホテルを予約する。会場への行き方と、キャンセルの条件を確認する。

## 3. お金
- [ ] 参加費の支払い方法（現金、カードなど）を、主催者の案内で確認する。
- [ ] 日本から 100 万円相当を超える現金を持ち出すときは、日本の税関に申告する（[税関](https://www.customs.go.jp/kaigairyoko/shiharaishudan.htm)）。
- [ ] 米国に **1 万ドル相当以上**の現金を持ち込む・持ち出すときは、**FinCEN 105** で申告する。同行者の合計で数える。申告しないと全額が没収されることがある（[CBP](https://www.cbp.gov/travel/international-visitors/kbyg/money)）。

## 4. 現地で
- [ ] カジノの入場は 21 歳以上。パスポートの原本を持っていく。
- [ ] 参加登録の方法（事前登録や現地の窓口）を、主催者の最新の案内で確認する。
- [ ] 入賞したら、支払いの窓口で**源泉徴収の扱い**を確認する。日本は租税条約の対象国で、ITIN と W-8BEN があれば源泉徴収されない扱いになり得る。無い場合は 30% が差し引かれる。
- [ ] 支払いの明細と、源泉徴収の書類を受け取って保管する。

## 5. 帰国後
- [ ] 日本の居住者は、海外で得た賞金も日本で申告の対象になる（一般に一時所得）。米国で源泉徴収された場合は、米国での還付の申告や、日本の外国税額控除を検討する。具体的な手続きは税務署や税理士に確認する。

## やらないこと
- オンラインの予選（サテライト）への参加。米国のオンラインポーカーは一部の州の中にいる人しか使えず、日本からの参加は日本の賭博罪になります（[法律と掲載ルール](/legal/)）。
